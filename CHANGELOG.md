# Changelog

## 1.0.0 - 2026-10-14

First public release.

- Live WebGL preview of the CRT effects.
- Export of a cool-retro-term profile (version 2) as a `.json` file, with a `rbgShift` copy for 1.2.x releases.
- Color rendering aligned with the official shader formula.
- Built-in presets and community themes from the wiki.
- Import of existing themes (pasted JSON or file).
- Interface in English, French and German.
- Light, dark and system appearance.
